Informasi Acara

Nama Acara Fun Run JOSJISZ 2026
Tema Run Together, Stay Healthy, Celebrate Indonesia
Penyelenggara RAWON Run Community
Deskripsi Fun Run JOSJIZ 2026 merupakan kegiatan olahraga yang mengajak masyarakat untuk hidup sehat melalui kegiatan lari bersama dengan suasana yang menyenangkan, aman, dan penuh kebersamaan.

Informasi Acara
• Tanggal: 21 November 2026.
• Waktu: 05.30–11.00 WIB.
• Tempat: Lapangan Nusantara, JOGJA.

Kegiatan Fun Run

Fun Run 5K

Peserta dapat mengikuti kegiatan lari sejauh 5 kilometer dengan rute yang aman dan menyenangkan.

Family Run

Kegiatan lari bersama keluarga yang dirancang untuk menciptakan pengalaman olahraga yang menyenangkan.

Health & Sport Talk

Sesi berbagi informasi mengenai kesehatan, olahraga, pola hidup sehat, dan persiapan sebelum melakukan aktivitas lari.
